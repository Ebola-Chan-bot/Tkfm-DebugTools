这是独立实现的战斗规则沙盘，包含颠倒镜与魔狱塔-55「夏日尾声」

# 运行与部署

Windows 可直接双击[一键启动服务器.cmd](一键启动服务器.cmd)，默认在 <http://127.0.0.1:5511/> 启动隐藏的独立后台进程，健康检查通过后打开浏览器。关闭启动窗口或VS Code不影响服务；重复双击复用已有进程，不注册开机自启。端口被其他程序占用时明确报错，不结束任何占用进程；缺少Node或构建产物时给出提示。启动器优先使用PowerShell 7，未安装时使用Windows PowerShell；Node优先从PATH读取，必要时通过Visual Studio安装器查找已有Node。

也可在本目录用PowerShell执行[启动服务器.ps1](启动服务器.ps1)，例如 `./启动服务器.ps1 -不打开浏览器` 或 `./启动服务器.ps1 -端口 5512`。首次准备构建产物或使用原来的前台预览方式，在本目录执行：

```powershell
npm ci
npm run build
npm run preview
```

本地地址为 <http://localhost:5510>。构建产物在本目录的 `dist/`，可部署到任意 HTTPS 静态目录；所有应用资源、manifest、Service Worker 均使用相对路径，可部署于 GitHub Pages 项目子目录。首次打开并显示“离线就绪”后，已缓存页面可断网运行。支持安装提示的浏览器会提供安装按钮，其他浏览器可使用自身的安装菜单。

所有编队和操作记录只保存在浏览器本地，可导入导出 JSON。切换关卡保留当前已应用编队、站位及全部养成设置，未应用的编队草稿也继续保留，不会被目标关卡的默认队伍或旧阵容覆盖。两关分别保存敌方与模型参数、战斗操作和进度；目标记录与当前编队相同则恢复原进度，不同则先逐份备份原记录，再以当前编队重新开始目标战斗，刷新后可在编队页导出最近备份。刷新恢复最近使用的关卡；未应用草稿仅在当前页面保留。CSV 包含逐回合伤害、有效及理论治疗、溢出治疗、护盾生成、护盾吸收、承伤和存活数。应用编队或模型设置会重置当前战斗。撤销与重做通过确定性操作重放实现。

页面切换由用户点击页签或“完整记录”等明确导航入口触发。切换关卡、应用编队、应用战斗设置、载入文件和重置战斗都只刷新当前页，不自动进入战场。当前浏览器标签页会记住用户选择的视图，刷新后恢复；这不表示未应用的编队草稿会自动保存，草稿仍可通过应用或导出保存。

# 编队与面板

编队支持1至5位角色。可用“添加角色”和每行的移除按钮调整人数，至少保留1位、最多5位；移除后站位顺次前移，第一位为队长。战场、回合报表、自动行动、存档与回放使用实际人数，不补入隐藏角色；夏日尾声仍保留原本五名敌人。技能中明确要求五人或指定站位的条件仍按原技能判断，不因少人队伍自动满足。

编队页的“导出编队”保存当前草稿为独立文件，包含角色顺序、羁绊、星级、调教、普通等级、潜力阶数与六节点、解放及ELV等级和单选技能，不包含关卡、战斗进度、手填生命／攻击或技能脚本。“载入编队”从该文件恢复草稿，确认后点击“应用编队”才替换当前战斗；与顶部导入／导出完整战斗记录的功能独立。空队、超出五人、重复角色、无效角色及不合法养成会被拒绝，载入失败不改动当前编队。

角色输入框用于搜索游戏中真实存在的SSR角色，不是角色创建器。支持范围仅限SSR，不支持SR、R、N；当前资料快照包含188位SSR及201个技能版本，188位均具备参考面板。可输入名称、编号、资料编号或“编号 完整名称”；匹配后载入真实编号、名称、职业、属性和已有面板，不生成任何自定义编号，也不允许改成虚构职业或属性。

完整名称优先唯一匹配，简繁全名可直接使用；简称或部分名称存在多个候选时必须进一步选择，不擅自取第一位。比如“魔剑”可能指不同角色，而“终焉魔剑薇塔”可唯一匹配编号10212。未知名称、未知编号、编号与名称不符以及同队重复编号均被拒绝。

真实角色身份与技能建模是两件事。188位SSR现在统一使用真实文本模型，不再以原8位手工模型兜底。当前普通技能、队长、星级被动、潜力被动及16位角色的真实三阶段解放均进入同一编译与执行流程；星3至5、羁绊1至5及可用解放阶段共3540档。命令行覆盖报告包含逐档结果、37条ELv定义、资料指纹及校核依据，不在编队页面显示或导出；未知目标、未知效果、空普攻／必杀和不适用ELv选择均明确阻断。编译完整、运行无异常和官方实测正确是三个不同结论，不能互相代替。

旧技能规则记录不能按当前规则直接回放。载入本地旧记录时逐份保存备份，不覆盖此前备份；编队页可以导出原始记录，草稿的解放阶段须重新确认。虚构角色或占位技能不继承为真实模型，未知或重名输入仍待逐位选择，不从虚构编号猜角色。新的默认队伍只使用真实SSR。

[真实角色目录.json](真实角色目录.json)由[生成角色目录.mjs](生成角色目录.mjs)使用TypeScript语法树读取本地Data-Room的SSR角色资料和参考面板表生成，只提取数据字面量，不执行上游脚本，也不打包剧情、图片或上游战斗代码。非SSR资料不生成、不进入匹配或技能查询；不再实现其初始星级换算。目录随应用发布和离线缓存，不依赖运行时跨站查询。SSR稀有度与敌方关卡星等、SSR自身的养成档位是不同概念，本限制不改变敌方关卡规则。更新资料时在本目录运行：

```powershell
node 生成角色目录.mjs
```

生成器使用TypeScript 5.9的稳定Compiler API和OpenCC开发依赖，只静态提取字面量。简体原文保留不变，备用繁体校核说明独立保存；严重引号错误使用版本／解放阶段限定的结构校核，并强制所有数值顺序与原文一致。原文更新导致数值指纹不符时生成失败，不能继续静默套用旧校核。

界面每人具有普通等级（1至60）、ELV突破等级（0至20）、调教（0至3档）、星级（SSR的3至5星）、潜力（1至12阶）及当前阶六个节点选择。生命和攻击只显示一组只读结果，不允许填写，也没有另一组基准面板或重复预览。计算直接使用角色资料中的初始HP／ATK，不读取配置中的手填生命／攻击或旧基准字段；即使在编队JSON中改动这些数值，战斗也会按真实资料和养成重新计算。

普通等级倍率为 `1.1^(等级-1)`，星级倍率为 `(1+0.2×目标星级)/(1+0.2×初始星级)`，调教分别对应0%、5%、15%、30%。潜力按角色真实类型累计：低于所选阶的节点已全部开启，当前阶仅累计勾选节点，HP与ATK分别求和后各自相乘；被动节点只解锁对应潜力技能，不误算为属性百分比。解放基础面板与ELV累计加成另计，例如ELV1仅攻击增加0.6%，ELV2两项各增加0.6%，ELV20两项各增加6%。各倍率合算后稳定向下取整，不先对中间基准取整。

初始属性、潜力类型、12阶六节点表、普通等级及ELV数据均由[生成角色目录.mjs](生成角色目录.mjs)静态提取，纯数据随应用离线发布。新建角色默认60级、三星、调教3、潜力12全节点、ELV0，界面可明确修改实际养成；潜力6阶与12阶的被动节点分别控制对应技能。旧手填面板不能反推出真实潜力，旧模型记录保留备份，草稿需重新确认潜力及解放；不再沿用原固定3.25参考系数。首轮必杀冷却仍按实际冷却初始化，再应用已解锁的开场减CD。

ELV突破要求60级及潜力5满或6以上，界面和战斗结算均校验资格。降低普通等级或潜力使资格失效时，ELV归零并取消未解锁的突破技能；切换潜力阶数时清空新阶节点选择，之前各阶按已完成计算。生命／攻击输出为进场前属性，队长、被动及所选ELv技能在战斗内独立结算，不重复叠加。

普通技能的修订号不是解放等级。默认使用截止日期为空的当前修订，历史说明保留；解放从独立资料按阶段1、2、3累积覆盖指定技能。露露阶段1替换指定技能，阶段2基础HP／ATK提升10%，阶段3进一步替换队长与被动，不能把普通历史修订2当作解放1。

ELv不是基础调教。折叠选择区收录37条真实技能，只显示当前SSR职业和属性适用的项目；保存真实编号、资料指纹并显式参与初始技能。每个强化分类单选、最多生效一项，不同分类和角色互不干扰；选择“未强化”可清空该类，默认不自动选择技能。同类多选的旧配置或导入记录会被拒绝，须重新选择，不擅自保留其中一项。职业强化Ⅰ、通用强化、属性强化、职业强化Ⅱ分别在ELV5、10、15、20解锁，未达到等级的选项禁用，降低等级取消超出门槛的已选技能；程序导入的未解锁选择也拒绝进入战斗。达到门槛不代表账号已经消费材料取得技能，仍须按游戏内实际情况显式选择，不自动生成账号养成方案。

文本模型支持命名子技能、相对阵营、职业／属性组合与最高最低筛选、层数和队伍条件、概率、生命／护盾／指定角色攻击基准、叠层保护、持续效果、吸血、祝福、控制、清除和冷却变化。随机状态保存在战斗JSON中，固定种子可确定性回放。事件按动作批次去重，多段伤害不冒充多次受击；同一具名状态和授予来源共享真实层数上限。

在本目录生成可复查的覆盖报告：

```powershell
node 编译技能文本.mjs --全档位
```

报告绑定编译器、引擎、角色资料和ELv数据的SHA-256指纹，显示实际未支持语句。它检查编译完整性，不冒充动作执行、全部账号养成组合或官方游戏数值验证。发布构建不包含这份开发报告、资料生成器或上游运行代码。

# 自动敌方行动

新建战斗默认启用自动敌方。选择我方五人的行动后，敌方自动结算并推进下一回合；“运行至结束”采用内置的我方示例策略连续运行，不是最优队伍搜索器。无需输入敌方技能、机制或时间表。旧记录保留可导出，不会按新语义静默重算；确认编队和面板后重新应用当前模型。

“战斗记录”展示回合统计及玩家可理解的行动、伤害、治疗和效果，技能显示名称而不是内部编号。底层仍保留AI命中轨迹、条件与规则槽位供内部核查，但网页不展示独立的AI诊断表或导出入口。战斗记录导入导出仍包含配置与我方操作，可用于恢复和重放。

`解析敌方行动.mjs` 是只读原包分析工具，不进入发布产物。EnemyAI 整表1225条，每条703字节，含20个35字节规则；两关六名敌人的43条记录均逐字段对照。运行规则在 `敌方行动规则.mjs`，不加载原包或反混淆计算器。

```powershell
node 解析敌方行动.mjs 43248 42281 42282 42283 42284 42285
```

直接证据包括技能引用、周期与余数、血线参数、人数参数及选敌码。原包测试敌人60136／60137的技能23976—23991明确写出条件60—65分别检测双方当回合普攻、必杀、防御次数。

仍需区分静态解释与已验证事实：条件16、42、45、76、78目前按最大／当前CD的大小或相等关系实现；规则的触发模式0／1／2按一次性、回合与条件变化事件处理，行为标志1停止当前扫描。这些语义来自跨敌人规则与技能文本的推定，尚未从受保护的IL2CPP方法直接验证。自动运行和回放验证通过，不能证明官方语义已经完整还原。字段比较符、初始冷却、敌方星等和事件检查时点仍是内部配置，网页不再提供这些研发校准控件；默认初始冷却1、每段伤害后检查事件。已有存档的内部参数保留，普通战斗设置不覆盖它们。实测还需核对CD比较方向、边界、重置时机、事件消耗行动及复合技能次序。

# 夏日尾声

目标为客户端关卡 60155（塔-55／夏日尾声），不是 60162「夏日尾声-SP」。Stage_C 的关卡编号是记录偏移 0 的 UInt16，偏移 17 的 UInt16 编组编号为 42096；MonsterGroup 引用五名单位：铃兰 42281、娜娜 42282、阿尔蒂雅 42283、露露 42284、静 42285。五份 Character_C、SkillGroup 与 EnemyAI 记录和中文技能文本共同确认了敌人及技能版本。

敌人各自保留生命、增益、嘲讽、防御和行动状态。我方选择攻击目标，嘲讽生效时只能选嘲讽者；全部存活敌人行动完才推进回合。铃兰的蓄力经过两回合后释放「慎防搭讪」，仅伙伴技能「关心铃兰」计入三次解除条件，我方伤害段不计入。铃兰被击破不代表通关，须击破全部五敌。

已纳入锁血、受盾压制、每回合攻击 +5%、5% 自疗、普攻按夏日层数叠攻、100 层攻击追加全体最大生命 500% 真实伤害、按最大生命排名选人，以及伙伴的防御减伤降低、普攻伤害降低、攻击降低。解除防御来自角色真实技能，成功后派发对应事件；娜娜的「别跑太远喵」有效时触发敌方全体受伤 +50%。没有这种技能的角色不会自动解除防御。

自动模式覆盖开场、人数变化、夏日层数、蓄力及伙伴行动，以下仍需校准：

- 五敌生命由原包参数计算，不读取实测HP：`floor(Character_C基础HP × 1.1^(Stage_C等级-1) × (1+0.2×Stage_C星等))`。60155的编组42096引用42281至42285，基础HP为1000000、850000、800000、775000、825000，等级68、星等4。五项计算结果逐整数等于ground truth：1068027439、907823323、854421951、827721265、881122637，误差均为0；删除实测验算字段后计算不变，改变基础HP、等级或星等则结果相应改变。
- 此前把原包基础值与资料站的初始属性混同：原包巴尔HP2173／ATK575，资料站初始值3476.8／920已经乘了三星1.6。资料站[General.ts](../../TKFM-Data-Room/plugins/utils/components/StatCal/General.ts)的星级表达式明确为`(1+0.2×目标星级)/(1+0.2×初始星级)`；对原包未乘星级的值应直接乘目标星级倍率，四星是1.8，不是1.2。全部188位SSR的初始HP交叉对照均一致，187位ATK一致；10187的ATK有来源差异，原包551与资料站等效基础477不一致，已记录待核对，不静默改变玩家数据。
- HP＋50%来自原包技能组被动3：铃兰28758，其余四人28803。本关只有四星，实测结果对应未启用这项五星被动；此前把1.5提前乘入，再反推出1.2，是两个错误互相抵消，不是合法倍率来源。被动原文、角色／技能组／关卡偏移、完整原始记录及源文件SHA-256保存在[真实敌方资料.json](真实敌方资料.json)，由现有生成器只读提取。未取得受保护客户端方法体，其他关卡、其他星等的条件仍须各自验证，不将本关HP复现冒充整个战斗引擎已精确还原。
- 五敌基础攻击原表均为500，按同一有来源的等级／星级属性公式得到534013，不再使用500占位或错误的356009外推值。但尚无独立的敌方攻击实测，攻击与伤害规则仍需验证。三类已知旧默认记录（基础HP×1.5、实测HP加基础ATK、旧错误攻击外推）先备份，再用原包公式重新开始并保留编队与其他设置；用户手动校准的数值不会自动覆盖。
