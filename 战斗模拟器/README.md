这是独立实现的战斗规则沙盘，包含颠倒镜与魔狱塔-55「夏日尾声」

# 运行与部署

在本目录执行：

```powershell
npm ci
npm run build
npm run preview
```

本地地址为 <http://localhost:5510>。构建产物在本目录的 `dist/`，可部署到任意 HTTPS 静态目录；所有应用资源、manifest、Service Worker 均使用相对路径，可部署于 GitHub Pages 项目子目录。首次打开并显示“离线就绪”后，已缓存页面可断网运行。支持安装提示的浏览器会提供安装按钮，其他浏览器可使用自身的安装菜单。

所有编队和操作记录只保存在浏览器本地，可导入导出 JSON。两关分别保存，切换关卡不丢失另一关记录；刷新恢复最近使用的关卡。CSV 包含逐回合伤害、有效及理论治疗、溢出治疗、护盾生成、护盾吸收、承伤和存活数。更改编队或模型设置会重置当前战斗。撤销与重做通过确定性操作重放实现。

# 夏日尾声

目标为客户端关卡 60155（塔-55／夏日尾声），不是 60162「夏日尾声-SP」。Stage_C 的关卡编号是记录偏移 0 的 UInt16，偏移 17 的 UInt16 编组编号为 42096；MonsterGroup 引用五名单位：铃兰 42281、娜娜 42282、阿尔蒂雅 42283、露露 42284、静 42285。五份 Character_C、SkillGroup 与 EnemyAI 记录和中文技能文本共同确认了敌人及技能版本。

敌人各自保留生命、增益、嘲讽、防御和行动状态。我方选择攻击目标，嘲讽生效时只能选嘲讽者；全部存活敌人行动完才推进回合。铃兰的蓄力经过两回合后释放「慎防搭讪」，仅伙伴技能「关心铃兰」计入三次解除条件，我方伤害段不计入。铃兰被击破不代表通关，须击破全部五敌。

已纳入锁血、受盾压制、每回合攻击 +5%、5% 自疗、普攻按夏日层数叠攻、100 层攻击追加全体最大生命 500% 真实伤害、按最大生命排名选人，以及伙伴的防御减伤降低、普攻伤害降低、攻击降低。自定义角色可以在技能中加入 `{ "类型": "解除防御", "目标": "首领" }`，解除当前敌人的防御；娜娜的「别跑太远喵」有效时触发敌方全体受伤 +50%。未录入这种效果的角色不会自动解除防御。

下列设置和机制不是已还原的官方 AI：

- 五敌默认生命采用 Character_C 基础值乘被动最大生命 +50%，基础攻击采用原始值 500，未计入关卡等级、养成或额外倍率；须在模型设置中分别校准，不能视为实战面板。
- 默认开场选技能 28759（受盾 -95%），可改为 28760（受盾 -125%、夏日 +1）或关闭后手动触发；条件码尚未解释。
- 「艳阳高照」「不能放弃！」「夏日的终结」和铃兰结束自伤等条件事件使用机制校准，不自动猜血线或触发次数。普通版减伤采用 28762 的 -25%／3 层，没有套用未被这组 AI 引用的 28776。
- 35981 的目标尚未解出，需手动指定；「解除娜娜防御」仅用于校准真实的解除事件，不能当作队伍天然拥有的技能。
- 并列最大生命、无防御优先目标均按站位；敌方施加的短时效果覆盖下一次我方回合；回合回血在敌方全员行动后、统一效果减时前结算。夏日 100 层追加在攻击动作后触发。这些时点仍需游戏实测。
- 受伤增减按同乘区相加；未实现属性克制。角色覆盖范围、治疗和护盾等共用假设见下文。

时间表使用「回合 敌人简称 技能」格式，同一回合每名敌人最多一行；未指定的存活敌人待机。机制校准不占行动，但会写入记录供撤销和重放。默认时间表为空，不冒充官方流程。

```text
1 铃兰 遭遇搭讪
1 娜娜 关心铃兰
1 阿尔蒂雅 关心铃兰
1 露露 关心铃兰
1 静 开心夏日
```

# 模型与边界

Boss 锚点为原始配置中的关卡 15249、编组 43146、单位 43248、技能组 432481。名称已核实为颠倒镜。第 27 季 SP-4 的界面对应仍以用户确认的敌人名称为锚，不把共享关卡模板的排列当作已恢复的官方赛季映射。

内置角色为露露、圣矮、奈奈美、闪黑、丧巴、花魁、商狐、拉尤；另有五个明确标注的自定义职业模板。数值规则按解包技能文本与 Data-Room 对应条目独立录入，界面列出每位角色的覆盖范围；不是通用全角色引擎。露露采用原包的三个技能组区分标准、部分解放和完全解放。角色初始面板默认乘以 3.25，养成、装备等差异可直接编辑生命与基础攻击；ELV 和其他解放专属变化未自动套用。

内核只使用普通 JSON 数据状态，没有上游计算器的函数、闭包或猴子补丁。新增角色可以编辑编队 JSON，使用 `初始`、`队长`、`普攻`、`必杀`、`防御`、`行动后`、`回合开始`、`队长必杀` 等事件和 `增益`、`治疗`、`持续治疗`、`护盾`、`伤害`、`解除防御`、`计数` 等效果。伤害默认指向选中敌人，可用 `"目标": "敌方全体"` 表示全体攻击。未知效果明确抛错，不静默丢弃。面板传入的是不含队长及被动加成的数值。

下列假设必须经游戏内实测校准，不能将当前结果当作官方精确模拟或通关保证：

- Boss 最终生命和基础攻击为占位值，尚未从关卡养成倍率完整恢复。
- 两条 50% 减伤默认在受伤乘区相加，治疗者和辅助者的对应易伤加在该乘区；其他叠加解释可调整 Boss 总减伤。造成伤害、技能伤害、触发效果与属性易伤使用独立乘区，非完整官方公式。
- 零有效回复默认仍触发被治疗事件；持续治疗默认在敌方行动后结算。两项均可切换；满血、零回复及触发治疗的行为需要实测。
- 最低血量按当前生命／最大生命比例实时选择，并列取站位靠前者；逆向重力按最大生命绝对值选最低者。并列规则尚未核实。
- 普通伤害计算防御与受伤加成。真实伤害默认绕过防御和减伤，但仍消耗护盾；死亡单位不接受治疗、不复活。
- 持续治疗快照施放时的攻击基数，同名同来源刷新时长；护盾按生成顺序吸收。治疗和各追加伤害的精确时点仍需校准。
- 99 次攻击效果按本模型产生的伤害段估计，可在蓄力期间手动校准，不等同于游戏的真实命中判定。
- AI 的条件码、血线和回合优先级没有还原。默认时间表只是普通攻击；手动技能和自定义时间表是用户设定，不是官方 AI。
- 默认只把收到的治疗事件分别触发一次；技能内各治疗效果按顺序处理，来源与触发类治疗的精确次数仍需游戏对照。

“颠倒世界”的职业差异使用当前敌人引用的新版 28862，而不是旧版 22812：攻击者攻击给予 Boss 方真实治疗；妨碍者与守护者攻击给予配置指定一方加攻；治疗者必杀追加 400% 攻击伤害，辅助者普攻追加 20% 攻击伤害。“防御触发易伤”的目标歧义也以可切换参数保留。
